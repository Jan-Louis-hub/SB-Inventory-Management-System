| Layer | Technology | Purpose |
| :--- | :--- | :--- |
| **Frontend** | React + Vite | User interface |
| **Language** | JavaScript or TypeScript | Frontend logic |
| **Styling** | Tailwind CSS | Responsive, consistent design |
| **UI components** | shadcn/ui or another React component library | Tables, dialogs, forms |
| **Charts** | Recharts | Sales and inventory analytics |
| **Backend** | Python + Flask | REST API and business logic |
| **ORM** | Flask-SQLAlchemy | Database models and queries |
| **Migrations** | Flask-Migrate | Safely update database schema |
| **Database** | PostgreSQL | Persistent application data |
| **Validation** | Marshmallow or Pydantic | Validate API request data |
| **Authentication** | Flask-JWT-Extended | Token-based authentication |
| **Testing** | Pytest + Vitest | Backend and frontend tests |
| **API communication** | Fetch or Axios | React-to-Flask requests |
| **Version control** | Git + GitHub | Track changes and collaboration |
